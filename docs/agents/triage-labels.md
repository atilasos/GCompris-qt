# Estados de triagem

Usa estes valores na linha `Status:` das tarefas locais.

| Papel | Valor | Significado |
| --- | --- | --- |
| needs-triage | needs-triage | Aguarda avaliação |
| needs-info | needs-info | Aguarda informação |
| ready-for-agent | ready-for-agent | Pronta para implementação por agente |
| ready-for-human | ready-for-human | Requer implementação humana |
| wontfix | wontfix | Não será implementada |

Para alterar a nomenclatura, edita a coluna Valor.
