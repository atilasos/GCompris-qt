# Dois pares legados para revisão linguística

Os ficheiros foram copiados diretamente do registo de recursos Qt carregado,
por File.copy durante um caso nativo offline. Não derivam de uma pesquisa de
imagens nem de gravações novas. `pairs.json` conserva os caminhos qrc exatos;
`capture-index.json` fixa tamanho/SHA256 dos quatro ficheiros. Texto fonte:
`src/activities/lang/resource/content-pt.json`, entradas fawn.ogg e tick.ogg.
O resultado nativo comprova a captura; não aprova as traduções ou pronúncias.

## fawn.ogg → «corso»

A imagem capturada mostra uma cria de cervídeo, com manchas no dorso. O texto
«corso» é uma entrada lexical diferente de «corço»: o Priberam associa a primeira
a pirataria/Córsega e a segunda a cervídeos. Isto sustenta a suspeita de uma
cedilha em falta. A escolha pedagógica entre «corço», «cervato» ou outra descrição
da cria deve conferir-se com a imagem e com a gravação legada capturada.

Fontes consultadas: [corso](https://dicionario.priberam.org/corso) e
[corço](https://dicionario.priberam.org/cor%C3%A7o), Dicionário Priberam.

## tick.ogg → «piolho»

A imagem capturada representa um animal arredondado com oito patas. A inferência
visual é de uma carraça; não é uma identificação zoológica de uma fotografia.
O Priberam distingue [carraça](https://dicionario.priberam.org/carra%C3%A7a)
de [piolho](https://dicionario.priberam.org/piolho), classificado como inseto.
O nome inglês do recurso também é tick. Há uma discrepância concreta a rever
entre imagem/conceito e texto PT, com gravação OGG disponível para conferência.

Não alterei estes dois textos nem qualquer áudio legado. Não afirmo ter ouvido
ou confirmado as palavras pronunciadas. Esta revisão semântica deve ter tarefa
própria e aceitação docente pendente; não deve ser confundida com aprovação
linguística integral do corpus a partir dos testes de entrada/correspondência.
