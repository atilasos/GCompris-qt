# Faísca provenance

The activity is an independent QML/JavaScript implementation of Faísca rules
referenced by atilasos' CRJM platform (https://github.com/atilasos/crjm).
No CRJM code, artwork or pedagogical text is copied or relicensed here.
The native source and original icon are GPL-3.0-or-later; build metadata is
BSD-2-Clause. Native acceptance uses a fixed legal game independently checked
against the CRJM reference runtime, including a jump and exhausted reserves.
